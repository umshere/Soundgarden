# Soundgarden

A three.js-powered globe that lets you explore and listen to handpicked radio stations from around the world. Smooth transitions, ambient lighting, and animated station markers create a modern take on classic radio discovery experiences like Radio Garden.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

> **Note:** Some radio streams may be geo-restricted or require interaction before playback in certain browsers.

## Features

- Immersive 3D earth rendered with physically based lighting and an atmospheric glow.
- Animated station beacons and orbiting halos that pulse at different cadences for depth.
- Smooth camera flights to the selected station with responsive UI updates.
- Lightweight UI panel that surfaces station details, playback controls, and quick links.
- Responsive layout with mobile-friendly controls.
